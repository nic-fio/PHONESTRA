Chapter 1

Welcome

1.1 · What Phonestra is

Phonestra is a Linux program that brings the apps of your Android phone to your PC. Each app opens in its own window, like a PC program, and is used with mouse and keyboard. The phone stays on the desk: it only needs to be on, unlocked and on the same Wi-Fi network as the PC.

The apps keep running on the phone, with their data and their accounts: Phonestra shows their picture on the PC and sends clicks and keystrokes to the phone. With Phonestra you can:

  • open the phone's apps in PC windows, even several apps at once;
  • type with the PC keyboard and copy and paste text in both directions;
  • hear the phone's audio through the PC speakers;
  • see the phone's notifications on the PC;
  • install apps, send files to the phone and receive files from it;
  • take screenshots and record an app's screen.
i
Nothing on the phone. no app is installed on the phone. Only a few Android settings are turned on, once (ch. 3 “Connecting the phone”). Whatever Phonestra changes on the phone while in use, it puts back the way it was at the end (15.1 “What changes on the phone”).

1.2 · Who this manual is for

First-time users can follow ch. 5 “First steps”: it goes from the downloaded file to the first app open on the PC in a few steps. The ch. 17 “Glossary” explains the less common words.

1.3 · Conventions

In this manual, “phone” always means the Android phone connected to Phonestra; “PC” means the computer running Linux. Phonestra's interface is in Italian: the manual quotes its labels exactly as they appear, with the English translation in parentheses where needed. The names of Android settings (for example Debug wireless for Wireless debugging) may vary slightly from one brand to another: the manual uses the most common ones.

i
Version. this manual describes Phonestra 1.0.0-rc.8. The internal workings are described in the Technical Manual (docs/Technical Manual.html). Some interface items are marked In arrivo (Coming soon): they do nothing yet, and the manual mentions them only to say so.
+
Appearance. Phonestra follows the desktop's light or dark theme. The figures in this manual are diagrams, not photographs: colors and proportions on your own screen may differ.
Chapter 2

Installation and first start

2.1 · Requirements

i
Unlocked phone. the phone must be unlocked while you use its apps from the PC: this is an Android security rule. Phonestra turns the phone's screen off while you use it from the PC and turns it back on at the end (ch. 12 “The phone's screen”).

2.2 · Downloading Phonestra

  1. Open Phonestra's releases page in your browser: https://github.com/nic-fio/PHONESTRA/releases.
  2. Download the Phonestra-<versione>-x86_64.AppImage file of the latest release.
  3. Move the file wherever you like, for example to your home folder. Phonestra runs from there: it does not need to be installed.
  4. Make the file executable, once only: in the file manager, right-click the file, “Properties”, the “Permissions” tab, the checkbox that allows running it as a program (the exact name varies from one desktop to another). Or from a terminal, with the command below.
Making the AppImage executable
$ chmod +x Phonestra-*-x86_64.AppImage
+
Optional check. the releases page also lists the file's SHA-256 fingerprint. If you want to check that the downloaded file is intact, compare it with the one computed by sha256sum.

2.3 · Starting Phonestra

Start Phonestra by double-clicking the file, or from a terminal:

$ ./Phonestra-*-x86_64.AppImage
  • Phonestra does not add icons to the system menu: to open it again, start the file again.
  • If Phonestra is already open, starting it a second time does not open a second Phonestra: it brings the drawer to the front (or reopens it if it had been closed).

2.4 · Closing Phonestra

Phonestra closes when all of its windows are closed: the drawer and the app windows. If you close only the drawer, the open apps stay open.

  1. Close the app windows and the drawer, with the × at the top right.
  2. Phonestra pauses any music or video the phone was playing, closes the apps open in windows and puts the phone back the way it was: screen back on, previous screen timeout and volume.
  3. After a few seconds the program exits.
i
From the terminal. if Phonestra was started from a terminal, Ctrl+C in the terminal also closes it in the same way, putting the phone back in order.
i
Sudden shutdowns. if the connection drops suddenly (PC turned off, Wi-Fi lost), the phone puts itself back in order a few seconds later; anything left over, Phonestra fixes at the next connection (15.1 “What changes on the phone”).

2.5 · Updating Phonestra

  1. Download the new release, as the first time, and make it executable.
  2. Close Phonestra, if it is open.
  3. Start the new release. The phone, preferences and favorites are kept: they live in ~/.config/Phonestra, not in the AppImage file.
  4. Delete the old release's file.

The version in use is shown in Informazioni (About), at the bottom of the drawer's sidebar.

Chapter 3

Connecting the phone

3.1 · Before you start

The first connection is done only once for each phone, without a cable, in a few minutes. Phonestra asks you to turn on four things on the phone; how to do it on your model you can find out with the search in the phone's Settings.

  • The phone: Android 14 or later, charged, unlocked, within reach.
  • The PC and the phone on the same Wi-Fi network.
  • Phonestra running: at first start Aggiungi un telefono (Add a phone) opens by itself; for an additional phone, open it from the drawer with Aggiungi telefono (Add phone) (13.1 “Adding another phone”).

3.2 · The “Aggiungi un telefono” window

The window is called Aggiungi un telefono (Add a phone). On the left, under the heading Prepara il telefono (Prepare the phone), is the list of the four things to do; on the right, the COSA VEDO IN RETE (WHAT I SEE ON THE NETWORK) and TI SEI BLOCCATO? (STUCK?) boxes and the button for the cable route.

Each item opens with a click and contains:

  • why it is needed, in plain words;
  • the DOVE SI TROVA (WHERE TO FIND IT) box, with the word to type into the search in the phone's Settings;
  • Fatto › (Done), to press when the item is done (the first three);
  • Chiedi a Google ↗ (Ask Google), which opens a Google search in the browser with the question already typed: it explains how to do it on your model, often with a video.
i
Automatic checkmarks. the items that Phonestra can see on the network get checked by themselves. The COSA VEDO IN RETE box says what it sees at that moment: ○ Nessun telefono col Debug wireless acceso (no phone with Wireless debugging on), ● Un telefono col Debug wireless acceso (a phone with Wireless debugging on), ● Schermata del codice aperta (code screen open).
+
Getting help. if you get stuck, the TI SEI BLOCCATO? box suggests taking a photo of the window and sending it to whoever recommended Phonestra: the window shows how far you have got.

3.3 · Step by step

  1. Check that the phone is on the same Wi-Fi network as the PC; press Fatto › (Done).
  2. Unlock the Opzioni sviluppatore (Developer options, item 2); press Fatto ›.
  3. If the phone has Blocco automatico (Auto Blocker) or Protezione avanzata (Advanced Protection) turned on, turn them off (item 3); press Fatto ›.
  4. In Opzioni sviluppatore turn on Debug wireless (Wireless debugging) and tap Consenti (Allow) for the network. Phonestra notices by itself and opens item 4.
  5. Tap the Debug wireless label, then Associa dispositivo con codice di associazione (Pair device with pairing code): the phone shows a 6-digit code.
  6. Type the 6 digits into the field of item 4. There is nothing to press: with the sixth digit Phonestra pairs, connects and saves the phone.
  7. When Fatto! «<nome del telefono>» è collegato via Wi-Fi. (Done! “<phone name>” is connected via Wi-Fi.) appears, press Inizia a usare il telefono (Start using the phone): the drawer opens.
i
No addresses. the phone's address and port don't need to be typed anywhere: Phonestra finds them on the network by itself.

3.4 · The 6-digit code

After pairing, Phonestra removes the expiry of this PC's authorization, so the connection doesn't have to be redone after a few days of not being used (15.2 “What stays switched on on the phone”).

3.5 · The cable route

The Android 10 o precedente? Collega col cavo (Android 10 or earlier? Connect with the cable) button, at the bottom right, opens the fallback route: the first connection with the USB cable, designed for phones that don't have Wireless debugging. Afterward the cable is unplugged and Phonestra works over Wi-Fi as always.

!
Android 14. the apps in the windows still require Android 14 or later: with an older phone Phonestra cannot show them, whichever route is used for the first connection.
  • The window moves on by itself: it notices every step done on the phone.
  • Without the Consenti sempre da questo computer (Always allow from this computer) checkmark the cable works but Wi-Fi doesn't: Manca «Consenti sempre» (“Always allow” missing) appears and the request must be repeated by unplugging and replugging the cable.
  • On Xiaomi, Redmi and Poco phones there is an extra step, Un passaggio in più per Xiaomi (One more step for Xiaomi): turn on Debug USB (impostazioni di sicurezza) (USB debugging (Security settings)), otherwise the apps are visible but don't respond to mouse and keyboard.
  • If after 20 seconds the window is still at the first step, the Cosa vede il PC (What the PC sees) box appears with the list of USB devices: it is useful to photograph for someone helping remotely.

3.6 · Later connections

After the first connection there is nothing more to do: at startup Phonestra looks for the phone on the network and connects by itself.

  • The phone must be on, unlocked, on the same Wi-Fi network and with Debug wireless (Wireless debugging) turned on.
  • Android sometimes turns Wireless debugging off by itself, for example when switching Wi-Fi networks. Just turn it back on in Opzioni sviluppatore (Developer options): the code doesn't need to be redone, the PC stays paired.
  • On a new network the phone asks again for Consenti (Allow) for that network.
+
Turning it back on quickly. many phones let you add Debug wireless to the Quick Settings tiles in the notification shade: that way it turns back on with one tap.
Chapter 4

The drawer at a glance

4.1 · How the drawer is laid out

The drawer is Phonestra's main window: it opens at startup and gathers the phone's apps, notifications, preferences and the phone's screen. The name comes from the Android app drawer, the place where Android keeps its apps.

  • The drawer follows the desktop's light or dark theme.
  • When you type while the drawer is in the foreground, the text goes into the Cerca un'app (Search for an app) search box: Enter opens the first app found.
  • Closing the drawer does not close the open apps; Phonestra quits when no window is left (2.4 “Closing Phonestra”).

4.2 · The phone pill

In the middle of the title bar is the phone pill: a colored dot, the phone's name and the connection status.

Clicking the pill opens the phone menu:

4.3 · The sidebar

4.4 · The phone screen in the drawer

On the right of the drawer is the drawn phone. When the connection works, it contains the phone's real screen, live, even if the phone's physical screen is off.

  • You use it with the mouse just like the app windows: a click is a tap, a drag is a swiping finger (7.1 “Mouse and touchpad”).
  • It is there for the things that are not apps: the Home screen, the notification shade, quick settings, recent apps, widgets. You open them as on the phone, with the mouse instead of your finger.
  • It receives keystrokes only after a click on the screen; a click elsewhere sends the keys back to the app search.
  • Dragging files onto the drawn phone sends them to the phone (10.3 “Sending files to the phone”).
  • Below the screen, a card appears for a transfer in progress (10.5 “The transfer in progress”).

When the phone cannot be used, a veil over the screen explains why:

i
Time and battery. above the drawn phone's screen, the time is the PC's; battery and network are the phone's, updated every half minute.

4.5 · Short messages

Short messages appear at the bottom of the window and disappear after a few seconds. In the drawer, for example:

  • Aspetta la fine del trasferimento in corso (Wait for the current transfer to finish): a file transfer is already in progress.
  • Il telefono non è collegato (The phone is not connected): the requested action needs the connection.
  • Rilettura delle app del telefono… (Rereading the phone's apps…): after Aggiorna ora (Refresh now) in the preferences.
  • <nome> aggiunto: lo trovi tra i telefoni (<name> added: you'll find it among the phones): after Aggiungi telefono (Add phone).
+
Where the files are. messages that end with the name of a folder (for example after a screenshot or a received file) tell you where the file is on the PC.
Chapter 5

First steps

5.1 · The path

This path takes you from a freshly downloaded Phonestra to the first app used on the PC, in five stages. Each stage points to the chapter that explains it in detail.

5.2 · Your first app

  1. With the phone unlocked and the drawer open, wait until the phone pill says collegato via Wi-Fi (connected via Wi-Fi) and the apps appear.
  2. Click an app, for example the messaging app. Or type its name and press Enter.
  3. The app opens in its own window. The phone's screen is off (Phonestra turns it off as soon as it connects): the phone stays on and unlocked, and Phonestra uses it without the screen (ch. 12 “The phone's screen”).
  4. Use the app with the mouse: a click is a tap, the wheel scrolls, the PC keyboard types.
  5. To go back to the app's previous screen, press the Indietro (Back) button at the top left, or Esc.
  6. To close the app, close its window: the app closes on the phone too.
+
The blue dot. a blue dot appears under the icon of an app that is open in a window. A second click on the icon does not open another window: it brings the already open one to the front.

5.3 · Home, Back and the notification shade

i
Why Home and Recents are missing. the app windows deliberately have no Home and Recent apps buttons: in Phonestra each app is a PC window, and windows are managed by the desktop.
Chapter 6

App windows

6.1 · Opening an app

Each phone app opens in its own window. There are many ways to open one, and several apps can be kept open at the same time.

  • A click on the app's icon in the drawer's App (Apps) page.
  • Typing the name into the Cerca un'app (Search for an app) search box (just start typing with the drawer in front) and pressing Enter: the first app found opens.
  • From the PREFERITI (FAVORITES) card, at the top of the page, with the apps chosen as favorites.
  • With a click on a notification, in the Notifiche (Notifications) page or in the system alert (ch. 9 “Notifications”).

If the app is already open, its window comes back to the front: each app has only one window. The list shows the apps that have an icon in the phone's app screen, including Impostazioni (Settings) and Fotocamera (Camera).

i
Newly installed apps. the app list is read at connection time and after every installation done by Phonestra. If an app just installed on the phone is missing, Preferenze (Preferences) › Aggiorna ora (Refresh now) rereads it.

6.2 · An app's menu

Right-clicking an app in the drawer opens its menu:

6.3 · Anatomy of a window

An app's window has a bar at the top with a few buttons; everything else is the phone's app.

App windows are ordinary desktop windows: you can move them, tile them side by side, make them full screen, and they appear in the desktop's taskbar with the app's name.

6.4 · Size, rotation and portrait-only apps

The app adapts to the window: when you widen the window, the app gets more room, as on a tablet; when you narrow it, it goes back to looking like the phone. The same happens when you maximize the window to full screen.

  • Ruota (Ctrl+R) swaps the window's width and height: a tall, narrow window becomes wide and short. It does not work with a maximized window or during a recording.
  • To enlarge the app's content (a map, a photo), use zoom: Ctrl + wheel, Ctrl++ and Ctrl+−, or a pinch on the touchpad (7.1 “Mouse and touchpad”).
i
Portrait-only apps. some apps accept only the phone's portrait shape (for example some social networks). For these the window has a fixed size: it cannot be maximized or resized by dragging its edges. If it was wide, it goes back to portrait by itself.

6.5 · Closing an app

  1. Close the window with the × at the top right, or Altri comandi › Chiudi app (More commands › Close app), or Ctrl+W.
  2. The app closes on the phone too: it is removed from the recent apps.
  3. If the app was playing music or a video, it is paused, so the phone does not keep playing on its own.
i
Closed, not stopped. the app is not force-stopped: it keeps receiving its notifications, as when you close it from the recent apps on the phone.

6.6 · When the connection drops

If the connection drops (the Wi-Fi is interrupted, the phone locks), the windows do not close. The last image of the app stays, blurred, with a veil that explains what is happening.

  • Phonestra retries by itself, every few seconds. Riconnetti ora (Reconnect now) retries right away.
  • When the connection comes back, the app reappears in its window, where it was.
  • Chiudi (Close) closes the window.
  • If the phone is only locked, the veil does not appear: the subtitle changes to Telefono bloccato: sbloccalo per continuare (Phone locked: unlock it to continue). After unlocking, Phonestra reconnects by itself.

6.7 · Protected screens

Some apps protect certain screens: banking apps, passwords, paid videos. Android does not let them be shown outside the phone.

Instead of the black image, Phonestra shows Schermata protetta (Protected screen): Questa app non permette di mostrare questa schermata fuori dal telefono. Le altre schermate dell'app funzionano normalmente. (This app does not allow this screen to be shown outside the phone. The app's other screens work normally.)

+
With the phone in hand. for protected screens, use the phone in hand: when you unlock it, its screen turns back on (12.2 “The phone in hand”).
!
No tricks. Phonestra does not get around protected screens: it is a security choice made by the apps and by Android.
Chapter 7

Mouse, keyboard and clipboard

7.1 · Mouse and touchpad

In the app windows, and on the phone screen in the drawer, the mouse acts as your finger.

i
Maps. some apps have their own zoom with the plain wheel, without Ctrl: maps, for example.

7.2 · Keyboard and shortcuts

The PC keyboard types into the app that has the focus. Some keys do extra things:

+
Keys in the drawer. in the drawer, keystrokes go to the app search. To type on the phone screen in the drawer, click the screen first.

7.3 · Typing with the PC keyboard

The on-screen keyboard of the phone does not appear: you type with the PC's keyboard, using its key layout (Italian, if the PC is set to Italian).

  • Letters, numbers and common symbols reach the app as if they had been typed on the phone.
  • Accented letters (à, è, ì, ò, ù) and less common symbols go through the phone's clipboard: Phonestra puts them in the phone's clipboard and pastes them into the app.
  • Shortcuts with Ctrl reach the app as they would from a keyboard connected to the phone.
!
Phone clipboard. typing an accented letter replaces the phone's clipboard with that letter. If something had been copied on the phone to be pasted, paste it first.

7.4 · The clipboard

The clipboard works in both directions, automatically, for plain text only.

  • If there is no text in the PC's clipboard, Ctrl+V shows Negli appunti del PC non c'è testo (There is no text in the PC's clipboard).
  • Text copied on the PC goes to the phone only when you paste it, and only to the connected phone.
  • For images and files, use Invia file… (Send files…) and Ricevi file… (Receive files…) (ch. 10 “Apps and files”). A Phonestra screenshot still ends up in the PC's clipboard as an image.
i
GNOME. on some desktops (GNOME, for example) a program can change the clipboard only while one of its windows is active. If text copied on the phone cannot be pasted on the PC, click a Phonestra window and try again.
Chapter 8

Audio, calls and camera

8.1 · Audio from the PC

While Phonestra is connected, the audio of the phone's apps comes out of the PC's speakers (or headphones). The phone stays silent.

  • This applies to all apps: music, videos, games, notification sounds, navigation.
  • Audio starts a few seconds after the connection: it may be missing in the first moments.
  • Audio and video stay in sync, recordings included (11.2 “Recording the screen”).
  • When Phonestra closes, any music or video that was playing is paused: the phone does not start playing again on its own through its loudspeaker.
i
Apps that forbid capture. some apps forbid capturing their audio. Their sound does not reach the PC: while Phonestra is connected they stay silent.

8.2 · Volume

Volume is adjusted on the PC, as for any other program: with the keyboard's volume keys or with the desktop mixer, where Phonestra shows up as a program playing sound.

During the connection Phonestra turns the phone's media volume all the way up: some apps do not start their audio when the phone's volume is at zero. The phone still makes no sound, because the audio comes out only from the PC. When it closes, Phonestra restores the previous volume.

!
Volume left high. in some cases, when Phonestra closes, the phone's media volume may stay at maximum. This is a known issue: if it happens, just lower it with the phone's keys.
+
Phone keys. the phone's volume keys have no effect while you use Phonestra: what counts is the PC's volume.

8.3 · Calls

Calls stay on the phone: you answer and talk with the phone in hand.

  • When a call comes in, Phonestra turns the phone's screen back on, so you can answer from the phone (12.4 “Incoming calls”).
  • Android does not allow the voice of calls to be carried to the PC: even with Phonestra you hear it from the phone.
  • The PC's microphone does not reach the phone.

8.4 · Camera and microphone

Apps open in a Phonestra window use the camera and microphone of the phone, as always.

  • A video call open in a window works: you see it on the PC, but it films and listens from the phone.
  • To take photos with the Camera app in a window, point the phone and click to shoot.
  • The phone does not become a webcam or a microphone for the PC's programs.
Chapter 9

Notifications

9.1 · The “Notifiche” page

The drawer's Notifiche (Notifications) page shows the phone's notifications, newest first. The number next to Notifiche in the sidebar says how many there are.

  • Notifications are grouped by app, in cards showing the app's name and how many notifications it has.
  • For each app you see the last 2; the altre N notifiche di <app> › (N more notifications from <app>) button shows the others.
  • Each notification has an icon, title, text and time. Clicking a notification opens the app in its window.
  • The × next to a notification hides it: Nascondi (sul telefono resta) (Hide — it stays on the phone). Nascondi tutte (Hide all), at the top, hides them all.
  • With no notifications the page says Nessuna notifica (No notifications).
  • Notifications refresh every few seconds, as long as the phone is connected.
i
Hiding does not delete. hiding a notification removes it only from Phonestra: it stays on the phone. If the app updates it (for example a new message arrives in the same chat), it reappears.

Ongoing notifications, the ones that stay while an app is working (for example music playing or a navigation app), do not appear, nor do notifications with no title and no text.

9.2 · Pop-up alerts

When a new notification arrives on the phone, Phonestra shows a system alert, like those of the PC's other programs: it appears in the corner of the screen and stays in the desktop's notification list.

  • Alerts respect the desktop's “Do Not Disturb”.
  • Alerts arrive only while Phonestra is open and connected to the phone.
!
Alerts at startup. when the drawer opens, the notifications already on the phone may each produce an alert, as if they were new. This is a known issue: later alerts only concern new notifications.

9.3 · Choosing the alerts

In the Preferenze (Preferences) page, NOTIFICHE (Notifications) tab, you choose what the alerts show.

  1. Open Preferenze (Preferences) in the sidebar.
  2. In the NOTIFICHE (Notifications) tab, press the button next to App che possono avvisare (Apps that can alert).
  3. In the App che possono avvisare window, turn off the switch of the apps that should not produce alerts. The choice is saved immediately.
+
Muted, not hidden. apps muted here keep appearing in the Notifiche (Notifications) page: the choice applies only to pop-up alerts.
i
Private notifications. Phonestra reads the title and text of all the phone's notifications, including those the phone hides on the lock screen. They stay on the PC, in Phonestra (15.3 “Privacy and security”).
Chapter 10

Apps and files

10.1 · Installing an app

Phonestra installs on the phone apps downloaded as .apk files, with no cable and without going through the phone.

  1. In the drawer press Installa app… (Install app…) and choose the file (the Scegli l'app da installare (Choose the app to install) window shows only App Android (.apk) (Android apps (.apk)) files). Or drag the .apk file onto the phone drawn on the right of the drawer.
  2. Phonestra asks for confirmation: Installare «<file>»? (Install “<file>”?). Press Installa (Install).
  3. The transfer card, on the drawn phone, shows the progress, then installazione in corso… (installing…).
  4. At the end «<file>» installata (“<file>” installed) appears and the app joins the drawer's list.
!
Trusted apps only. when installing from the PC, Android does not ask the usual confirmation for “unknown sources”. Install only apps you trust: the confirmation window reminds you of this.
i
Only .apk. packages split into several files (.apks, .xapk, .apkm) cannot be installed: Phonestra accepts only .apk files.

10.2 · Uninstalling an app

  1. In the drawer, right-click the app and choose Disinstalla… (Uninstall…).
  2. Phonestra asks for confirmation: Disinstallare <app>? (Uninstall <app>?) with L'app e i suoi dati verranno tolti da «<telefono>». (The app and its data will be removed from “<phone>”.) Press Disinstalla (Uninstall).
  3. If the app was open, its window closes. At the end <app> disinstallata (<app> uninstalled) appears: the app leaves the list and the favorites.
i
System apps. system apps (the ones the phone already came with) cannot be uninstalled: the menu item is grayed out, with App di sistema: non si può disinstallare (System app: cannot be uninstalled).

10.3 · Sending files to the phone

Files sent from the PC arrive in a folder on the phone, Download unless you chose another, and show up right away in the phone's Gallery and file app.

  1. In the drawer press Invia file… (Send files…) and choose one or more files (Scegli i file da inviare, Choose the files to send). Or drag them from the file manager onto the drawn phone: Rilascia per inviare al telefono (Drop to send to the phone) appears.
  2. The transfer card shows the file's name and Invio al telefono · <inviati> di <totale> (Sending to the phone · <sent> of <total>).
  3. At the end «<file>» è in Download sul telefono (“<file>” is in Download on the phone) appears (or in the chosen folder).
  • A file with the same name as one already there does not replace it: it arrives with a number, for example foto (1).jpg.
  • An .apk file dragged onto the phone is not copied but installed, after confirmation.
  • The destination folder on the phone is chosen in Preferenze (Preferences) › File inviati al telefono (Files sent to the phone): Download, Documenti (Documents), Immagini (Pictures), Fotocamera (Camera), Musica (Music) or Video.

10.4 · Receiving files from the phone

Without a cable, the PC's file manager does not see the phone. To copy photos and documents from the phone to the PC, use Ricevi file… (Receive files…).

  1. In the drawer press Ricevi file…: the Ricevi file dal telefono (Receive files from the phone) window opens, on the Recenti (Recent) place.
  2. Choose a place on the left, then open folders with a click. The path at the top and the Cartella superiore (Parent folder) arrow take you back.
  3. Click the files to receive: they get checked. Checks stay even when you change folder, and at the bottom you see how many files are selected and how big they are.
  4. Press Ricevi (Receive). The window closes and the files arrive in the PC's Scaricati (Downloads) folder (shown at the bottom: Arrivano in Scaricati, They arrive in Downloads).
  5. At the end N file ricevuti in Scaricati (N files received in Downloads) appears, with the Apri la cartella (Open folder) button.
  • You see the phone's shared storage, the same you see with a cable: not the apps' private data.
  • Whole folders cannot be received: open the folder and use Scegli tutti (Select all).
  • Hidden files (those whose name starts with a dot) do not appear.
  • Received files keep the phone's date; if a file with the same name already exists, the new one arrives with a number, for example foto (1).jpg.
  • With a single file, Apri la cartella (Open folder) opens the folder with the file already highlighted.
+
Another folder. the destination folder can be changed once and for all in Preferenze › File ricevuti dal telefono (Preferences › Files received from the phone; 14.1 “The “Preferenze” page”).

10.5 · The transfer in progress

Sends, installations and receptions happen one at a time. During the transfer, at the bottom of the drawer's drawn phone, there is a card with the file's name, the progress and a × to cancel.

Chapter 11

Screenshots and recording

11.1 · Taking a screenshot

A screenshot captures the app in a window at the phone's resolution, without the window's title bar.

  • The file is named after the app, the date and the time: for example Mappe 2026-09-30 10.42.05.png.
  • The image on the clipboard can be pasted right away into another PC program (an email, a chat, a document).
  • If the app does not show anything yet, Nessuna immagine da fotografare (No image to capture) appears.
i
Protected screens. a protected screen (6.7 “Protected screens”) comes out black in the screenshot too.

11.2 · Recording the screen

  1. In the app's window press Registra lo schermo (Record the screen; the button with the red dot).
  2. The button turns into a red pill with the elapsed time, for example ● 0:42.
  3. To stop, press the button again: Registrazione salvata in Video/Phonestra (Recording saved in Video/Phonestra) appears.
  • The video is an MP4 file in Video/Phonestra, named after the app, the date and the time, for example Mappe 2026-09-30 10.42.05.mp4.
  • The video is saved exactly as it arrives from the phone, without re-encoding: it is small and does not slow down the PC.
  • It includes audio too, which is the audio of the whole phone, not just of the app.
  • During recording the app does not change shape: if you resize the window the image adapts, but the video keeps its initial size. Ruota (Rotate) does not work.
  • If you close the window during a recording, the video is saved before the window closes.
+
With audio. to record with audio, it is best to wait a few seconds after connecting: audio starts shortly after the picture (8.1 “Audio from the PC”).
Chapter 12

The phone's screen

12.1 · Why the screen turns off

As soon as it connects, Phonestra turns off the phone's screen. The phone stays on and unlocked: the apps keep running and responding to the PC's mouse.

  • With the screen off you save battery and keep what you do from the PC private.
  • Android allows apps to be shown on the PC only while the phone is unlocked: this is why Phonestra does not let it fall asleep. During the connection it sets the screen timeout to the maximum and at the end it restores it.
  • Incoming notifications do not turn the screen back on: the phone only vibrates.
  • The phone screen in the drawer keeps showing, live, what the phone would have on its screen.
!
Touches with the screen off. with the screen off the phone is not asleep: the glass can still receive touches. Do not put it in your pocket or bag while Phonestra is connected.

12.2 · The phone in hand

When you pick the phone up again, the screen turns back on and stays on; when you put it down again, it turns off again.

i
With the drawer open. while the drawer is open, closing the last app does not turn the phone's screen back on: the drawer still shows the phone's screen and keeps it off.

12.3 · Locked phone

If the phone locks (for example with the power button, or with a double tap on the screen while it is off, a gesture on some brands), apps can no longer be shown: it is an Android security rule.

  1. The drawer shows Telefono bloccato (Phone locked) with Sbloccalo per continuare: mi ricollego da solo. (Unlock it to continue: I will reconnect on my own.); the app windows say Telefono bloccato: sbloccalo per continuare (Phone locked: unlock it to continue).
  2. Unlock the phone with your PIN, fingerprint or face.
  3. Phonestra reconnects on its own and the apps come back in their windows, where they were. The phone's screen stays on, because the phone is “in hand”; it turns off again at the first click from the PC.
i
A few seconds of waiting. on some phones (for example Samsung ones) locking drops the connection: for a few seconds riconnessione… (reconnecting…) appears. This is normal.

12.4 · Incoming calls

Calls are made and received with the phone in hand (8.3 “Calls”).

  • When the phone rings, Phonestra turns the screen back on: you answer from the phone as always.
  • During the call the screen does not turn off on its own, even if the phone is not touched (you do not touch it while it is at your ear).
  • After the call the screen stays on; it turns off again at the first click from the PC or after the phone's screen timeout.
+
Answering from the PC. a call of an app open in a window (for example WhatsApp) can also be accepted with a click on the PC; the voice, however, always goes through the phone.
Chapter 13

Multiple phones

13.1 · Adding another phone

Phonestra can remember several phones, but it uses one at a time. The phone in use is the “active” one; the others appear in the drawer's sidebar, under TELEFONI (phones), marked non attivo (not active).

  1. In the drawer, press Aggiungi telefono (Add phone), in the sidebar.
  2. The Aggiungi un telefono (Add a phone) window opens: follow the steps as for the first phone (ch. 3 “Connecting the phone”).
  3. At the end the drawer says <nome> aggiunto: lo trovi tra i telefoni (<name> added: you will find it among the phones). The active phone does not change.
i
Only your own phones. Phonestra only shows the phones connected with Aggiungi telefono, never those of other people on the same network.

13.2 · Switching to another phone

  1. In the sidebar, click the non attivo phone (the tooltip says Passa a <nome>, switch to <name>).
  2. If there are open apps, Phonestra asks for confirmation: Chiudere N app di «<attivo>» e passare a «<altro>»? (close N apps of <active> and switch to <other>?) with Un solo telefono alla volta: le finestre delle app si chiudono. (only one phone at a time: the app windows close). Press Passa (Switch).
  3. Phonestra closes the windows, puts the previous phone back as it was and restarts connected to the other phone.
+
The next start. the phone you choose becomes the one Phonestra opens at the next starts.

13.3 · Renaming a phone

  1. Click the phone pill, at the top of the drawer, and choose Rinomina… (Rename…).
  2. In the Rinomina il telefono (rename the phone) window, type the new name and press Rinomina (Rename).

The name changes only in Phonestra (Il nome si vede solo in Phonestra., the name is only visible in Phonestra): the phone's name in its own settings stays as it was. The initial name is the one the phone gives itself.

13.4 · Forgetting a phone

“Forgetting” a phone removes it from Phonestra. This is useful, for example, when you change phones or give one away.

  1. Click the phone pill and choose Dimentica questo telefono… (Forget this phone…).
  2. Read the Dimenticare «<nome>»? (forget <name>?) window and press Dimentica (Forget).
  3. Phonestra closes, putting the phone back as it was. If other phones remain, it restarts connected to the first one; otherwise, at the next start Aggiungi un telefono (Add a phone) opens.
!
On the phone too. forgetting the phone does not disconnect it on the phone's side: the PC stays paired. To remove it, on the phone: Debug wireless › Dispositivi associati (Wireless debugging › Paired devices; or, if it had been connected with the cable, Opzioni sviluppatore › Revoca autorizzazioni debug USB, that is Developer options › Revoke USB debugging authorizations).

To connect it again, just use Aggiungi telefono.

Chapter 14

Preferences

14.1 · The “Preferenze” page

The Preferenze (Preferences) page opens from the drawer's sidebar. Every change takes effect immediately and is saved automatically: there is no Save button.

i
For all phones. the preferences apply to all phones. Favorites and the name, on the other hand, belong to each phone.

14.2 · Where preferences are saved

The preferences are kept in the file preferenze.toml, in the folder ~/.config/Phonestra (15.4 “The folders on the PC”). There is no need to open it: the Preferenze (Preferences) page is enough.

To go back to the initial preferences, close Phonestra and delete preferenze.toml: at the next start every item goes back to its default value. The connected phone is not lost, because it is stored in another file.

i
Scaricati. if you choose the Scaricati (Downloads) folder again in File ricevuti dal telefono (Files received from the phone), Phonestra follows the desktop's downloads folder even if it changes in the future.
Chapter 15

Phone, PC and privacy

15.1 · What changes on the phone

To work, Phonestra changes a few things on the phone, only while it is connected. When it closes it puts them back as they were, even if the connection drops suddenly.

  • No app is installed on the phone, and nothing is left behind after closing.
  • If Phonestra does not close properly (PC switched off abruptly, Wi-Fi lost), the phone puts itself back in order a few seconds later. If something stays changed, Phonestra restores it at the next connection: it remembers the previous values on the PC.
  • After closing, the phone stays unlocked with the screen on: it turns off and locks by itself, after its screen timeout, as always.
!
Volume. in some cases the media volume can stay at the maximum after closing (8.2 “Volume”): just lower it with the phone's buttons.

15.2 · What stays switched on on the phone

Some things switched on for the first connection stay on even after Phonestra closes, so that next time there is nothing to do again.

i
Public networks. with Wireless debugging on, the phone announces itself on the Wi-Fi network. Only PCs paired with the code can connect. On networks other than your home one (hotel, office, public places) it is advisable to turn it off when you are not using Phonestra.

15.3 · Privacy and security

  • No internet. Phonestra only talks to the phone, on the home network. It does not send data to external servers, and has no advertising or usage statistics. The only exception is Chiedi a Google ↗ (ask Google) in Aggiungi un telefono, which opens the browser on a search, only if you press it.
  • Encrypted connection. Everything between PC and phone travels encrypted, with the same protection as Android's Wireless debugging.
  • Phonestra's key. The PC identifies itself to the phone with a secret key, in the file ~/.config/Phonestra/adbkey. Anyone who has that file can connect to the phone as Phonestra: do not copy or share it.
  • Notifications. Phonestra reads the title and text of the phone's notifications to show them on the PC. It does not keep them: they only remain while Phonestra is open. With Solo il nome dell'app (only the app name) the desktop alerts do not show sender and text.
  • Clipboard. Passwords copied on the phone do not pass to the PC, and those copied on the PC from a password manager do not pass to the phone (7.4 “The clipboard”).
  • PC screen. While Phonestra is open, anyone looking at the PC sees the phone's apps and notifications.
  • Protected screens. Screens that apps protect (banking, passwords) never reach the PC.
+
Leaving the PC. to leave the PC for a while, just close Phonestra: the phone goes back to how it was and nothing is left open on the PC.

15.4 · The folders on the PC

Phonestra does not write anywhere else: no menu icons, no services that start with the PC, no changes to the system. Deleting ~/.config/Phonestra brings Phonestra back to how it was at the first start.

i
Folder names. ~ is the home folder. The names Immagini, Video and Scaricati are those of an Italian-language desktop: Phonestra uses the folders the desktop has chosen for pictures, videos and downloads (on an English-language desktop, Pictures, Videos and Downloads).

15.5 · Removing Phonestra

  1. Close Phonestra, so that the phone goes back to how it was.
  2. Delete the file Phonestra-<versione>-x86_64.AppImage.
  3. Delete the folders ~/.config/Phonestra and ~/.cache/Phonestra (in the file manager they are hidden folders: they appear with “Show Hidden Files” or Ctrl+H).
  4. If you no longer need them, delete Immagini/Phonestra and Video/Phonestra too.
  5. On the phone: Debug wireless › Dispositivi associati (Wireless debugging › Paired devices), remove the PC; then turn off Debug wireless and, if you like, Opzioni sviluppatore (Developer options).

After these steps nothing of Phonestra is left, neither on the PC nor on the phone.

Troubleshooting

16.1 · Common problems

16.2 · Phonestra's messages

16.3 · Phonestra's log

Phonestra writes a log of what it does: connections, drops, screen on and off, errors. It helps whoever is helping you understand a problem.

  • If you start Phonestra from a terminal, the log lines appear in the terminal.
  • If you start it with a double-click, they usually end up in the system log (the journal) and can be read with the command below.
Today's lines
$ journalctl --user --since today | grep -i phonestra
i
Before sharing it. the log may contain the phone's name and the names of apps. Before sending it to someone, read it through and remove whatever you do not want to share.
+
What to send. along with the log, a picture of the window with the message is useful, and the Phonestra version (Informazioni, About).

16.4 · Limitations to be aware of

  • Only one phone active at a time (ch. 13 “Multiple phones”).
  • The phone must stay on, unlocked and on the same Wi-Fi network as the PC.
  • Calls, including those made from apps, are heard and made on the phone. Text messages are read and written with the messaging app, in a window, like the other apps.
  • The PC's microphone and webcam do not reach the phone; the phone does not act as a webcam for the PC.
  • Protected screens stay black; apps that forbid capturing their audio stay silent.
  • Notifications hidden in Phonestra stay on the phone: Phonestra does not delete the phone's notifications.
  • Opzioni sviluppatore (Developer options) and Debug wireless (Wireless debugging) can only be turned on by hand, on the phone: Android does not allow a program to do it.
  • Only single .apk files can be installed.
  • Phonestra is made for Linux on 64-bit Intel or AMD processors.
Chapter 17

Glossary

17.1 · Terms

Android
The phone's operating system. Phonestra works with Android 14 and later.
AppImage
A Linux program in a single file, which starts without being installed. Phonestra is distributed this way.
Clipboard
The copied text, ready to be pasted. Phonestra passes it between phone and PC (7.4 “The clipboard”).
Desktop pop-up
The desktop notification (pop-up alert) that Phonestra shows when a notification arrives on the phone.
Developer options
A hidden menu in Android's Settings; it is unlocked by tapping the build number 7 times.
Device pairing
The first meeting between phone and PC, with the 6-digit code: afterwards, the phone recognizes the PC on its own.
Drawer
Phonestra's main window, with the phone's apps, notifications and screen (ch. 4 “The drawer at a glance”).
In hand
The phone while you are using it with your hands: the screen stays on until you go back to the PC (12.2 “The phone in hand”).
Phone screen in the drawer
The live copy of the phone's main screen, on the right of the drawer, to be used with the mouse.
Pill
The rounded box at the top of the drawer with the phone's name and status.
Pinned apps
The favorite apps, chosen with a right-click and shown at the top of the App page.
Protected screen
A screen that an app does not allow to be shown outside the phone: in Phonestra it stays black, with a message.
Screen timeout
How long the phone waits without being touched before it turns the screen off and locks.
Toast
A short message that appears at the bottom of the window and disappears by itself.
Wi-Fi guest network
A separate Wi-Fi network for guests, offered by many routers: devices connected to it cannot see each other, and Phonestra does not find the phone.
Wireless debugging
A setting in Android's Developer options that lets a paired PC connect to the phone over Wi-Fi (in Phonestra's Italian interface: “Debug wireless”). Phonestra uses it for everything.
