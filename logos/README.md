# Grafica

Logo di Phonestra fornito dall'utente il 28 set 2026; varianti ricavate il
28 set. Il simbolo senza scritta è il logo del programma: barra del drawer
(`icons/phonestra-48.png`), finestra «Informazioni» e icona del file AppImage
(`icons/phonestra-256.png`). L'icona provvisoria di prima
(`costruzione/phonestra.svg`) è stata tolta.

| File | Cosa | Uso |
|---|---|---|
| `phonestra-logo.png` | originale, 1254×1254, fondo bianco pieno | riferimento |
| `phonestra-logo-transparent.png` | fondo trasparente, schermo e tasto bianchi | sfondi chiari |
| `phonestra-logo-dark-background.png` | come sopra, scritta bianca | sfondi scuri |
| `phonestra-symbol.png` | solo telefono, anello e pixel, quadrato, trasparente | icone, favicon |
| `icons/phonestra-<n>.png` | simbolo senza scritta a 16…512 px | icona del programma e **barra in alto dell'app** (da 32 px in su è nitida) |
| `phonestra-logo-horizontal-light.png` / `-dark.png` | simbolo a sinistra, scritta a destra | intestazioni, pagina del progetto |
| `icons-with-text/phonestra-<n>-light.png` / `-dark.png` | logo completo quadrato a 128, 256, 512 px | dove serve l'icona col nome (sotto 128 px la scritta non si legge) |
| `phonestra-symbol.svg` | simbolo ridisegnato a mano in vettoriale | **approssimazione**: anello un po' più sottile e regolare; il riferimento resta il PNG |

Varianti trasparenti: il bianco diventa trasparente tranne lo schermo del
telefono e il tasto; i bordi sono senza alone bianco. Scartata una versione
senza sfondo fatta con un altro strumento (alone colorato sfrangiato, buco
nello schermo).
